# Tensegrity Robot USD Assets

[← Back to resources](../README.md) · [Project root](../../README.md) · [Robot specification](../../doc/Tensegrity_robot/tensegrity_robot.md)

Simulation-ready USD files for the **5-DOF ceiling-mounted tensegrity
manipulator**.  The 3-DOF arm USDs are generated by
[`tools/build_tensegrity_arm_usd.py`](../../tools/build_tensegrity_arm_usd.py)
from the Blender-exported source mesh.  The 5-DOF manipulator USDs are
assembled via Isaac Sim Robot Assembler by combining the arm, the 2-DOF
linear base, and (optionally) the Robotiq 2F-140 gripper.

For full robot documentation (kinematic chain, joint specs, actuation modes)
see the [Tensegrity Robot docs](../../doc/Tensegrity_robot/README.md).

## Directory Contents

| Directory | Description |
|-----------|-------------|
| [`meshes/`](meshes/) | Blender-exported source mesh (`tensegrity_arm_cad.usdc`) and mini-wrist STL files |
| [`threedof_arm/`](threedof_arm/) | 3-DOF tendon-driven arm USD variants (generated by build script) |
| [`fivedof_manipulator/`](fivedof_manipulator/) | 5-DOF full robot USDs (arm + base ± gripper, assembled via Robot Assembler) |
| [`twodof_base/`](twodof_base/) | 2-DOF linear ceiling-mount base USD |
| [`twodof_wrist/`](twodof_wrist/) | 2-DOF wrist test USD |

## 3-DOF Arm Variants

| File | Elbow Model | Meshes | Description |
|------|-------------|--------|-------------|
| `tensegrity_threedof_arm_elbow_approx.usd` | Disc approximation | Full-res | Single revolute elbow joint with cylinder mesh |
| `tensegrity_threedof_arm_elbow_approx_lo.usd` | Disc approximation | Low-res | Decimated visual meshes, same collision geometry |
| `tensegrity_threedof_arm_physical.usd` | Antiparallelogram linkage | Full-res | Four-bar linkage with crossing rods + loop-closure joint |
| `tensegrity_threedof_arm_physical_lo.usd` | Antiparallelogram linkage | Low-res | Decimated visual meshes, same collision geometry |
